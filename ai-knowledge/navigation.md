# Where things are (routes)

- /dashboard — Today list, getting-started checklist, pipeline numbers, recent deals
- /outbound — Client Radar: start a search, review prospects, outreach queue, inbox (where Gmail is on)
- /leads — the leads pipeline · /leads/:id — a lead (facts, outreach, next steps, timeline, Turn into a deal)
- /deals — deals list or board · /deals/new — create a deal · /deals/:id — deal details (quote/agreement actions live here)
- /deals/:id/quote — quotation document view
- /quotations — quotations register
- /contracts — agreements list · /contracts/:id — agreement details (signing link, invoice actions) · /contracts/:id/export — print/PDF view
- /invoices — invoices list · /brand-invoices/:id — invoice document (mark paid, attachments)
- /agent — Agent mode: one conversation (and voice) that finds, prepares and asks before changing anything
- /profile — personal + business info, bank details, signature
- /settings — Organization, Team Members (invite, roles & permission matrix), Integrations (Gmail), Activity Logs, Subscription, Preferences (theme)
- /pricing — plans & billing (in the app)
Top navigation on desktop (Home, Client Radar, Pipeline, Documents, Money) with a Workspace | Agent switch; bottom navigation on mobile.
